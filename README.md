# fpga-ip-axilite-axistream-
Configurable AXI4-Lite/AXI4-Stream Based FPGA Processing IP Core — A SystemVerilog-based FPGA IP core implementing AXI4-Lite control/data interfaces with configurable processing logic, verified using ModelSim and synthesized/implemented in Xilinx Vivado.
